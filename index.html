Reconcile — Excel add-in

This page hosts a Microsoft Excel task-pane add-in. There's nothing to use here directly — the add-in runs inside Excel.

To install it, sideload the manifest: manifest.xml

See the README for step-by-step sideload instructions.

Already installed? Read the how-to-use guide — laying out your data, running a reconciliation, reading the colours, and the =RECON. formulas.

All matching runs locally in your browser/Excel. No data leaves your machine.
