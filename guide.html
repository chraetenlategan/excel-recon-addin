Reconcile — how to use it

Install page Technical README

Reconcile matches a cashbook against a bank statement and/or a general ledger by amount + date, right inside Excel. Everything runs on your own machine — no data leaves it.

One-time setup. Ask whoever set this up to install it for you (see the install page). Once installed, updates are automatic — you never re-install. When it's in, you'll see a Reconcile button on the Excel Home tab.

1. Lay out your data

Put each dataset on its own worksheet (tab). Name them clearly — e.g. Cashbook, Bank Statement, Ledger.

Each sheet needs a header row with these columns (any order — they're detected automatically):

  • Date
  • Description (payee / reference / narrative)
  • Amount — or a Debit column plus a Credit column instead.

Money-in is positive, money-out is negative. (1,234.56) and 1,234.56- both count as negative.

2. Run a reconciliation

  1. Home ▸ Reconcile to open the panel on the right.
  2. Pick which tab is the Cashbook, plus at least one of Bank statement / General ledger.
  3. Click Load & detect columns.
  4. Check the detected columns. Wrong guess? Change the drop-downs (Date / Description / Amount, or switch to Debit + Credit). You can also set a month filter.
  5. Click Reconcile.

New sheets appear, named Recon - … (Comparison, Cashbook, Bank Statement, Unmatched). Your original tabs are never changed.

Reading the colours

ColourStatusMeans
GreenMatched Amount, date and description all line up.
AmberCheck description Amount + date match, but the description doesn't — eyeball it.
RedNot found No row with the same amount + date on the other side.

The Recon - Unmatched sheet goes further: it suggests which leftover rows probably belong together (including one payment that hit the bank as several lines), then lists whatever it couldn't pair.

3. Spot-check a single row with a formula

To check one row without running a full reconcile, type a formula in a blank cell. Excel will autocomplete the name as you type =RECON.:

=RECON.COMPARETOBS(amount, date, description)

Example — in a cashbook row where amount is in D2, date in B2, description in C2:

=RECON.COMPARETOBS(D2, B2, C2)

The cell shows Matched to Bank Statement, Check description (Bank Statement), or Not found on Bank Statement. Drag the fill handle down to check a whole column.

Three versions, one per target sheet:

FormulaChecks against
=RECON.COMPARETOBS(…)Bank statement
=RECON.COMPARETOGL(…)General ledger
=RECON.COMPARETOCB(…)Cashbook (use it from a statement/ledger row)

Description is optional. If it picks the wrong target sheet, add the sheet name as the last argument: =RECON.COMPARETOBS(D2, B2, C2, "Bank Feb").

Troubleshooting

ProblemFix
No Reconcile button on the Home tab The add-in isn't installed on this machine — see the install page, then restart Excel.
Detected the wrong columns Change the drop-downs after Load & detect, or give your columns clearer headers (Date / Description / Amount).
Dates don't match though they look the same Usually fine — it reads day/month/year in any order. If not, format both columns as real dates (not text).
#NAME? from a =RECON. formula Add-in not loaded yet — open the Reconcile panel once, or restart Excel.
A formula says No … sheet found Pass the exact sheet name as the last argument, e.g. =RECON.COMPARETOBS(D2, B2, C2, "Statement").

All matching runs locally in Excel. No data leaves your machine.
