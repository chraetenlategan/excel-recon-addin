Reconcile — how to use it

Install page Technical README

Reconcile matches a cashbook against a bank statement and/or a general ledger by amount + date, right inside Excel. Everything runs on your own machine — no data leaves it.

The panel has two modes, switched at the top:

  • Classic — the cashbook / bank / ledger flow described below. Use it when your data looks like accounting data.
  • Modular — any sheets, any columns. You say which columns to compare and it reconciles them. See Modular Recon.
One-time setup. Ask whoever set this up to install it for you (see the install page). Once installed, updates are automatic — you never re-install. When it's in, you'll see a Reconcile button on the Excel Home tab.

1. Lay out your data

Put each dataset on its own worksheet (tab). Name them clearly — e.g. Cashbook, Bank Statement, Ledger.

Each sheet needs a header row with these columns (any order — they're detected automatically):

  • Date
  • Description (payee / reference / narrative)
  • Amount — or a Debit column plus a Credit column instead.

Money-in is positive, money-out is negative. (1,234.56) and 1,234.56- both count as negative.

2. Run a reconciliation

  1. Home ▸ Reconcile to open the panel on the right.
  2. Pick which tab is the Cashbook, plus at least one of Bank statement / General ledger.
  3. Click Load & detect columns.
  4. Check the detected columns. Wrong guess? Change the drop-downs (Date / Description / Amount, or switch to Debit + Credit). You can also set a month filter.
  5. Click Reconcile.

New sheets appear, named Recon - … (Comparison, Cashbook, Bank Statement, Unmatched). Your original tabs are never changed.

Reading the colours

ColourStatusMeans
GreenMatched Amount, date and description all line up.
AmberCheck description Amount + date match, but the description doesn't — eyeball it.
RedNot found No row with the same amount + date on the other side.

The Recon - Unmatched sheet goes further: it suggests which leftover rows probably belong together (including one payment that hit the bank as several lines), then lists whatever it couldn't pair.

3. Spot-check a single row with a formula

To check one row without running a full reconcile, type a formula in a blank cell. Excel will autocomplete the name as you type =RECON.:

=RECON.COMPARETOBS(amount, date, description)

Example — in a cashbook row where amount is in D2, date in B2, description in C2:

=RECON.COMPARETOBS(D2, B2, C2)

The cell shows Matched to Bank Statement, Check description (Bank Statement), or Not found on Bank Statement. Drag the fill handle down to check a whole column.

Three versions, one per target sheet:

FormulaChecks against
=RECON.COMPARETOBS(…)Bank statement
=RECON.COMPARETOGL(…)General ledger
=RECON.COMPARETOCB(…)Cashbook (use it from a statement/ledger row)

Description is optional. If it picks the wrong target sheet, add the sheet name as the last argument: =RECON.COMPARETOBS(D2, B2, C2, "Bank Feb").

4. Modular Recon — anything against anything

The Classic flow knows what a cashbook is: it needs a Date, a Description and an Amount. Modular knows nothing about accounting and asks you to describe the comparison instead — so it will reconcile a stock count against a delivery note, an invoice list against a remittance, or any two sheets that ought to agree.

Switch to Modular at the top of the panel, then work through three steps:

  1. Sheets — click Load worksheets to pull in every tab of the workbook. For each one, click the row that holds its column names (it guesses, and is usually right). Untick anything that isn't part of the job.
  2. Model — each sheet is drawn as a box, each column as a line inside it. Drag from a column on one box to a column on another to say “compare these two”. Draw several lines between the same two sheets and a row only matches when all of them agree — that's how you express “same date and same amount”. Click a line to change how it's compared (as text, a number, a date, or digits only) or to remove it. Narrow panel? The Add a comparison pickers under the canvas do the same thing without dragging, and Suggest links up any columns that share a name.
  3. Results — press Reconcile. You get a block per pair of sheets: how many rows paired up, and every row that didn't. Click a row number to see it in context; Write sheets puts the whole thing into the workbook as Modular - … tabs, coloured the same way.

Reading the Modular statuses

StatusMeans
MatchedExactly one row on the other sheet has the same values in the columns you linked.
Matched (repeated value) It matched, but that combination of values appears more than once — the totals are right, but which row paired with which is arbitrary. Worth a look.
Not foundNothing on the other sheet has those values.
No valueOne of the linked columns was blank or unreadable on that row, so it was never compared. Two blanks are never treated as a match.

Modular compares values exactly, once tidied up — dates are read whatever way round they're written, numbers rounded to the decimals you choose, and text matched ignoring capitals. It never matches “approximately”, which is what lets it tell you that 30 rows on one side and 29 on the other means exactly one is missing. Use Colours to change the palette or to paint whole rows instead of just the compared cells.

Troubleshooting

ProblemFix
No Reconcile button on the Home tab The add-in isn't installed on this machine — see the install page, then restart Excel.
Detected the wrong columns Change the drop-downs after Load & detect, or give your columns clearer headers (Date / Description / Amount).
Dates don't match though they look the same Usually fine — it reads day/month/year in any order. If not, format both columns as real dates (not text).
#NAME? from a =RECON. formula Add-in not loaded yet — open the Reconcile panel once, or restart Excel.
A formula says No … sheet found Pass the exact sheet name as the last argument, e.g. =RECON.COMPARETOBS(D2, B2, C2, "Statement").
Modular: Reconcile stays greyed out Nothing has been linked yet — draw at least one line on the Model step, between columns on two different sheets.
Modular: everything comes back No value The header row is probably wrong, so the column you linked isn't the one you meant. Go back to step 1 and click the right row.
Modular: dates that look identical don't match A column is read one way round for all of its rows. If a sheet mixes 07/17/2024 with 15/07/2024, format that column as real dates in Excel and reload the worksheets.
Modular: you changed the data in Excel Press Load worksheets again — it refreshes the values and keeps every comparison you drew.

All matching runs locally in Excel. No data leaves your machine.
